AgentLink demo website

Questo pacchetto contiene la demo pubblicabile online.

File principali:
- index.html
- assets/agentlink-logo.png

Pubblicazione semplice:
1. Vai su https://app.netlify.com/drop
2. Trascina la cartella AgentLink-site
3. Netlify genera un link pubblico temporaneo
4. In seguito puoi collegare un dominio tipo agentlink.it / agentlink.eu

Nota:
Questa versione salva le aziende nel browser locale del visitatore.
Per raccogliere aziende vere online serve collegare un database, ad esempio Supabase, Airtable o Firebase.
